KAWIT WIDIA — PERSONAL WEBSITE
================================

FILES
- index.html  : Main website
- style.css   : Responsive modern styling
- script.js   : Indonesian/English switch, mobile navigation, CV summary download

RUN LOCALLY
1. Extract this ZIP file.
2. Open the folder.
3. Double-click index.html. The website will open in your browser.
4. Internet is needed for Google Fonts. The site itself does not require a server.

PUBLISH FREE WITH GITHUB PAGES
1. Sign in to GitHub.
2. Create a new public repository, for example: kawit-widia-portfolio
3. Upload index.html, style.css, and script.js to the repository root.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait for deployment. GitHub will show your public website address.

BEFORE PUBLISHING
- Check that the WhatsApp number and email are correct.
- Confirm the work history and add exact employment dates if available.
- Add real work samples to the portfolio; current cards are clearly sample categories.
- Add a PDF CV if you want a PDF download button. The current button downloads a text CV summary.
- Consider adding a professional profile photo if you want one (not currently included).
- The page uses Google Fonts; if unavailable, system fonts will be used.
